# 下一版开发计划：归因可解释性

> 更新：2026-08-21。目标不是单纯提高样本内 R²，而是让产品分类、因子选择、样本外验证和页面结论形成可信闭环。

## 1. 目标与非目标

### 目标

1. 为股票量化、商品 CTA、期权/波动率和其他产品选择不同的因子集合；
2. 提高样本外解释的稳定性，并在不通过时明确拒绝结论；
3. 将“为什么可信 / 为什么不可信”直接展示在产品研究页；
4. 让批量产品的分析状态可见、可重跑、可存档。

### 非目标

- 不通过增加大量因子或搜索大量交互项来追逐 R²；
- 不从净值反推真实持仓、交易方向、杠杆、成本或管理人技能；
- 不把负样本外 R² 的产品包装为可预测；
- 不根据排名或归因自动写入组合权重或交易指令。

## 2. 当前基线与问题

当前通用 CTA 因子可完成基础、动态、市场环境和补充检验，但不同产品共用同一因子篮子会产生两类问题：

- 对股票量化或期权/波动率产品，商品 CTA 因子缺少经济对应关系；
- 在样本内加入更多变量可以提高 R²，却可能让样本外 R² 更差。

因此，本版以“先分类、后建模；先验证、后解释”为顺序。负样本外 R² 的默认处理是：保留业绩与风险指标，展示“当前模型不适用”，不展示强化的未解释收益、收益贡献或风格结论。

## 3. 目标流程

```mermaid
flowchart LR
    nav[已确认且已审核净值] --> labels[名称标签与人工策略]
    labels --> bucket[研究分池]
    bucket --> factors[匹配的版本化因子集]
    factors --> base[可解释的基础模型]
    base --> validate[滚动样本外验证]
    validate -->|通过| explain[归因、风险与结论]
    validate -->|不通过| reject[显示模型不适用与补数建议]
    explain --> archive[分析结果存档]
```

名称标签只是初步入口；人工策略、披露和净值统计冲突时必须保留冲突，不可强行覆盖。

## 4. 分池与因子合同

| 产品池 | 进入依据 | 第一批因子 |
| --- | --- | --- |
| 商品 CTA | 已确认商品/期货策略，或名称标签 CTA 且人工确认 | 中短长期趋势、截面动量、期限结构 Carry、跨期价差动量、波动状态、南华商品指数 |
| 股票量化 / 股指 | 股票、股指、指数增强、量化选股等人工确认 | 股指市场、规模、价值、质量、动量、行业/风格代理、波动状态 |
| 期权 / 波动率 | 期权、波动率或相关披露确认 | 标的市场、实现波动率、隐含波动率、波动率期限结构、偏度/凸性代理 |
| 混合或未确认 | 标签冲突、资料不足或跨类别 | 只保留风险与基础市场参考，不输出专属风格结论 |

每个因子必须保存来源、频率、可得日期、计算规则、连续合约规则、缺失处理、数据版本和截止日。缺失时显示“未覆盖”，不以零或横截面均值代替。

实现原则：名称标签不回写数据库；人工确认策略作为正式分池依据；分池逻辑和因子清单由后端单一入口决定；每个结果保存采用的产品池、因子版本与拒绝原因。

## 5. 模型与验证规则

### 基础模型优先

基础模型保持线性、少因子和可解释：

`产品收益 = 常数项 + 因子关联系数 × 因子收益 + 残差`

LASSO / Elastic Net 用于共线性下的辅助筛选与收缩，不单独构成经济结论；页面同时保留稳定的基础模型结果。

### 样本外准入

1. 使用 expanding-window 或滚动训练，训练期必须早于测试期；
2. 至少三个连续测试段，不能随机打乱时间；
3. 报告样本内 R²、样本外 R²、样本外误差、方向一致性、正增量测试段比例和参数敏感性；
4. 只有样本外结果在多数测试段稳定改善，才允许动态、市场环境或交互模型升级基础结论；
5. 若样本外 R² 为负或不同窗口频繁反转，结论降级为“当前模型不适用”。

交互项只允许预登记、具备经济解释的少量候选，首批仅保留“趋势 × 波动率”。训练期提升、单一窗口提升或大量搜索后的最佳结果都不能通过准入。

### 结论分级

| 状态 | 条件 | 页面行为 |
| --- | --- | --- |
| 可解释 | 样本、时间对齐和 OOS 稳定性通过 | 展示因子关联、收益/风险贡献和市场环境结论 |
| 仅供观察 | 样本勉强足够但稳定性不足 | 展示指标和警告，不生成强结论 |
| 模型不适用 | OOS 为负、显著性不足或数据缺失 | 展示业绩/风险，隐藏或弱化归因与未解释收益结论，并给出补数建议 |

## 6. 页面与批量流程

### 产品研究页

新增“模型适用性”卡，固定展示：产品池、采用因子集、样本数、样本期、样本内 R²、样本外 R²、稳定性、主要警告和下一步建议。

术语使用“关联系数、统计风险贡献、未解释收益、市场环境表现、分析结果存档”；高级方法名如 LASSO 在方法说明中保留。

### 研究筛选

- 保留名称标签与相对波动分层；
- 增加产品池、模型适用性和最近分析日期筛选；
- 名称标签显示“初步识别”，人工策略显示“已确认策略”。

### 批量分析

对符合门槛的产品批量运行基础归因；动态、市场环境和补充检验仅在基础模型满足最低数据条件时运行。每个产品保存成功、拒绝或失败状态，不因一个产品失败中断全批次。

批量计算采用确定性后端任务；LLM 只在结果已保存后生成文字摘要。

## 7. 分阶段实施

### P0：分类与模型适用性

- 后端建立产品池选择与因子合同入口；
- 在产品研究页返回并显示模型适用性；
- 为负 OOS、低样本、因子缺失建立统一拒绝口径；
- 批量基础归因状态表与重跑入口。

验收：任一产品能明确看到“采用什么因子、为什么可解释或为什么不适用”；不同产品类型不会静默共用错误因子池。

### P1：股票与期权/波动率因子

- 接入股票风格和股指代理；
- 接入实现/隐含波动率、期限结构和凸性代理；
- 完成数据可得日、缺失与版本测试。

验收：股票、商品 CTA、期权/波动率至少各有一套可复现的因子合同；无数据时拒绝而非伪造。

### P2：多段样本外验证与解释卡

- 实现三个以上连续测试段的统一评估；
- 对基础、动态、市场环境和交互模型输出同一套 OOS 指标；
- 将模型适用性、拒绝原因和因子覆盖写入分析结果存档。

验收：合成数据可识别已知稳定关系；无关系或结构变化数据不会被样本内 R² 误判为通过。

### P3：批量材料化与排名衔接

- 为所有可研究产品批量生成基础归因结果；
- 将最近有效分析状态接入研究筛选和 CODEX 排名解释；
- 排名仍独立于配置决策，不因归因失败删除产品的业绩与风险信息。

验收：产品新增后自动刷新排名，批量分析可追踪完成率；全量排名不会被单产品临时快照覆盖。

## 8. 质量门与测试

- 单元测试：名称/策略分池、日期截止、缺失因子、负 OOS 拒绝、快照选择；
- 合成数据：稳定线性关系、时变关系、无关系、交互关系四类；
- 真实数据：抽样人工检查因子来源、日期对齐和分类冲突；
- 前端：明确区分初步标签、已确认策略、研究结果与历史存档；
- 最小验证：后端相关测试、`python -m compileall`、`cd frontend; npx tsc -b`。

## 9. 完成定义

下一版完成不以某个 R² 数值为验收目标，而以以下条件为准：

1. 每个产品使用可追溯、类型匹配的因子集；
2. 每个归因结论都有样本外状态和清晰边界；
3. 负 OOS 或证据不足时系统明确拒绝，不生成误导性解释；
4. 批量结果可复跑、可筛选、可存档；
5. LLM 无法改写任何计算、审核或准入结果。
